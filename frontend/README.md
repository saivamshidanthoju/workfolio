# WorkBridge Frontend

This folder contains the React + TypeScript frontend for WorkBridge. It uses Vite, Tailwind CSS, React Query, Zustand for auth state, Recharts for charts, and Framer Motion for animations.

Quick start

1. Install dependencies

```bash
cd frontend
npm install
```

2. Run development server

```bash
npm run dev
```

3. Build for production

```bash
npm run build
```

Environment

- The frontend expects the backend API at `VITE_API_BASE`. By default it uses `http://127.0.0.1:8000`.

Notes

- Auth tokens are stored in `localStorage` as `wb_token` and sent via `Authorization: Bearer <token>`.
- WebSocket connections include `?token=<jwt>` query param for authentication.
- The AI assistant calls the backend `/ai/ask` endpoint (a simple stub in the backend at `backend/app/api/routes/ai.py`).
# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
